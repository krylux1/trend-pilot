1. Общие положения

Оператор осуществляет обработку персональных данных пользователей в целях предоставления доступа к сервису Trend Pilot, обеспечения его работы и исполнения обязательств перед пользователями.

Настоящая Политика является общедоступным документом. Согласие на обработку персональных данных оформляется отдельно от настоящей Политики.

2. Какие данные мы собираем

В зависимости от использования сервиса могут обрабатываться:

  • Адрес электронной почты.
  • Уникальный идентификатор пользователя (UID).
  • Данные, необходимые для авторизации через Google.
  • Сохранённые пользователем идеи.
  • Статус подписки и срок её действия.
  • Идентификаторы платежей и сведения о результате оплаты.
  • Технические данные, необходимые для работы и защиты сайта.
  • Сведения о посещении сайта, если используется аналитика.

Оператор не получает и не хранит полные номера банковских карт пользователей. Платёжные данные обрабатываются ЮKassa.

3. Цели обработки данных

  • Регистрация и авторизация пользователей.
  • Идентификация пользователя.
  • Предоставление доступа к функциям Trend Pilot.
  • Сохранение и синхронизация пользовательских идей.
  • Предоставление платной подписки.
  • Проверка статуса и срока действия подписки.
  • Подтверждение и учёт платежей.
  • Обеспечение безопасности и стабильной работы сервиса.
  • Анализ посещаемости сайта, если подключена аналитика.
  • Обработка обращений пользователей.

4. Правовые основания обработки

Обработка персональных данных осуществляется на основаниях, предусмотренных законодательством Российской Федерации, включая согласие пользователя, необходимость исполнения договора и выполнение обязанностей, возложенных на Оператора законом.

5. Используемые сторонние сервисы

Google и Firebase

Google Authentication и Firebase Authentication используются для авторизации пользователей. Cloud Firestore используется для хранения пользовательских данных, сохранённых идей и сведений о подписке.

ЮKassa

Используется для приёма и обработки платежей. Оператор получает сведения, необходимые для подтверждения оплаты и предоставления подписки.

GoatCounter

Может использоваться для сбора статистики посещений и анализа работы сайта.

Указанные поставщики могут обрабатывать данные в соответствии со своими условиями использования и документами о защите данных.

Оператор не продаёт персональные данные пользователей. Данные могут предоставляться государственным органам в случаях, предусмотренных законодательством.

6. Хранение и передача данных

Для хранения пользовательских данных используется Cloud Firestore. Регион используемой базы данных — europe-west3 (Франкфурт, Германия).

При использовании Google и Firebase обработка данных также может осуществляться с привлечением инфраструктуры и поставщиков услуг Google в соответствии с условиями этих сервисов.

Обработка и возможная передача данных за пределы Российской Федерации осуществляются с учётом требований применимого законодательства.

7. Сроки хранения данных

Персональные данные хранятся в течение времени, необходимого для достижения целей обработки.

После прекращения использования сервиса или получения запроса на удаление данных Оператор рассматривает возможность их удаления с учётом законных оснований для дальнейшего хранения.

Информация, необходимая для подтверждения платежей и исполнения требований законодательства, может храниться в установленные законом сроки.

8. Защита персональных данных

Оператор принимает необходимые организационные и технические меры для защиты персональных данных от неправомерного доступа, изменения, раскрытия, уничтожения и иных неправомерных действий.

9. Права пользователя

Пользователь вправе:

  • Получать информацию об обработке своих персональных данных.
  • Требовать уточнения или обновления неточных данных.
  • Требовать блокирования или удаления данных в предусмотренных законом случаях.
  • Отозвать согласие на обработку персональных данных.
  • Обращаться к Оператору по вопросам обработки персональных данных.

Для реализации своих прав пользователь может направить обращение на адрес: alexneolead@gmail.com.

10. Отзыв согласия

Пользователь вправе отозвать согласие на обработку персональных данных, направив обращение Оператору по электронной почте.

После получения отзыва Оператор прекращает обработку персональных данных или обеспечивает её прекращение, если отсутствуют иные предусмотренные законом основания для продолжения обработки.

11. Изменение Политики

Оператор вправе обновлять настоящую Политику при изменении функциональности сервиса или требований законодательства.

Актуальная версия Политики размещается по адресу: https://trendpilot.ru/privacy.html.
